    url
    "value": 0.35
    ✔ Means: 35% CPU usage
    http://localhost:8080/actuator/metrics/system.cpu.usage

    Compare:
    used vs max → tells if memory is under pressure
    http://localhost:8080/actuator/metrics/jvm.memory.used
    http://localhost:8080/actuator/metrics/jvm.memory.max

    "value": 120
    ✔ Means 120 active threads
    http://localhost:8080/actuator/metrics/jvm.threads.live

    Shows:
    GC pause time
    frequency
    ✔ High values = performance problem
    http://localhost:8080/actuator/metrics/jvm.gc.pause


    What GOOD vs BAD looks like
    Metric	    Good	    Bad
    CPU	        <70%	    90–100% 🔥
    Memory	    stable	    keeps increasing 📈
    Threads	    stable	    keeps growing ❌
    GC	        occasional	frequent pauses ❌
